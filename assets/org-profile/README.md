# BaseLOG

### 생각을 기록하고 나누는 블로그 | 글쓰기부터 소통까지

## ✨ 주요 기능

| | |
|---|---|
| ✍️ **글쓰기** | Markdown 에디터와 도구 모음, 임시저장, 썸네일 고르기, 사진·파일 첨부 |
| 🗂️ **정리** | 내 카테고리(상·하위), 태그, AI 태그 추천 |
| 🔍 **발견** | 최신·트렌딩 글, 요즘 인기 태그, 글·사람 검색 |
| 💬 **소통** | 댓글·답글, 좋아요, 팔로우와 피드, 알림 |
| 🌙 **편하게** | 다크 모드, PC·휴대폰 화면 |
| 🛡️ **운영** | 신고·숨김·정지, 공지·업데이트 소식 |

## 🛠️ 기술 스택

- **화면**: React 18, TypeScript, Vite
- **서버**: Java 21, Spring Boot 4.1, 모듈러 모놀리스
- **데이터**: PostgreSQL 18, Flyway, Redis, MinIO(사진)
- **AI**: Google Gemini, Ollama(대체)
- **배포**: Docker Compose, GitHub Actions(main에 합치면 자동 배포), nginx
