# 020 팔로우 → 친구

- 요청: 2026-10-12 민서 "팔로우를 빼고 그럼 친구로 바꿔줘"
- 근거: 팀 공통 01 C-FRIEND-1(친구 맺기)·C-ACT-1(최근 활동 친구에게 보이기)은 공통 필수, 팔로우(010, 24 문서)는 개인 확장이라 빼도 공통 스펙과 어긋나지 않는다.
- 공통 스펙 001~016 문서는 바꾸지 않는다. 010 팔로우 스펙은 이 문서로 대체된다.

## 바뀌는 것

| 자리 | 전 (010 팔로우) | 후 (020 친구) |
|---|---|---|
| 관계 | 한쪽이 누르면 끝 | 요청 → 상대가 수락하면 친구 (001 친구 API 그대로) |
| 블로그 머리말 | 공개 글 · 팔로워 · 팔로잉, [팔로우] | 공개 글 · 친구 N, [친구 요청] / [요청 취소] / [수락]·[거절] / [친구 ✓] |
| 글 상세 작성자 칸 | [팔로우] | 친구 버튼 (같은 모양) |
| 피드 | 팔로우한 사람의 공개 글 | 친구의 공개 글 (수락 전 요청은 빠짐) |
| 알림 | 새 팔로워, 팔로우한 사람 새 글 | 친구 요청, 친구 수락, 친구의 새 글 (각각 끌 수 있음) |
| 팔로워·팔로잉 목록 화면 | /@주소/followers, /following | 없앰. 내 친구 목록·받은 요청은 설정 화면 |

## 정한 것

- 거절·요청 취소·친구 끊기는 상대에게 알리지 않는다(001 그대로).
- 같은 사람이 요청·취소를 되풀이해도 안 읽은 친구 요청 알림은 하나.
- 친구 수는 탈퇴한 상대(유예 포함)를 빼고 센다(친구 목록과 같게).
- follow 테이블과 남은 행은 되돌리기 쉽게 지우지 않는다. 탈퇴 정리만 계속 지운다.
- 옛 새 팔로워 알림과 그 끄기 설정은 V6 마이그레이션이 지운다.
- 005 글 상세의 viewer.followingAuthor는 005 필수 칸이라 남기되 항상 false.
- 글 공개 범위 "친구 공개"는 이번 범위가 아니다(팀 결정으로 꺼 둔 선택 기능 그대로).
